# 抽样与建模流程

项目围绕地标农产品南果梨购买意愿与营销策略展开，数据由电商评论和抽样问卷两部分构成。

## 1. 电商评论分析

使用 Python 抓取电商平台评论，进行文本清洗、SnowNLP 情感分析、TF-IDF 高频词统计和词云输入表构建。
评论关注点主要包括口感、品质、包装、物流、价格和品牌认知。

## 2. 三阶段 PPS 抽样

问卷覆盖东北三省 43 个行政区，按地区规模进行 PPS 抽样，并围绕产品认知、质量感知、价格接受、
渠道信任和购买意愿设计量表。

## 3. 信效度与消费者画像

对量表题项计算 Cronbach alpha、KMO 和近似 Bartlett 检验，形成消费者画像特征。

## 4. K-means 与 Logistic 回归

K-means 用于消费者分群，Logistic 回归用于识别购买意愿影响因素，并将显著因子映射到质量追溯、
品牌标准化和渠道营销策略。
